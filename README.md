# Godot Mobile Keyboard Disabler

A Toggle Button in the main toolbar to disable the Android virtual keyboard while editing code on the Scripts screen.

# Quick Start

1. Copy addons/mobile_keyboard_disabler/ into your project's addons/ folder.
2. Enable Mobile Keyboard Disabler in Project → Project Settings → Plugins.

> If enabled, it displays a Toggle Button in the upper right corner of the editor that is used to activate/deactivate the device's virtual keyboard.
