# Godot Mobile Keyboard Disabler

A toggle button in the main toolbar to disable Android's virtual keyboard anywhere text can be entered in the editor: the Script editor, Inspector fields, FileSystem search, rename dialogs, SpinBox number entry, and more.

# Quick Start

1. Copy addons/mobile_keyboard_disabler/ into your project's addons/ folder.
2. Enable Mobile Keyboard Disabler in Project → Project Settings → Plugins.

> If enabled, it displays a Toggle Button in the upper right corner of the editor that is used to activate/deactivate the device's virtual keyboard editor-wide. New fields (dialogs, newly selected nodes, etc.) are picked up automatically while it's on.

## What version to use?

- If you are looking for the keyboard *lock* to apply to *all* Godot content, use version 1.2.0.
- If you are looking for the keyboard *lock* to apply *only* to the *Scripts screen*, use version 1.1.0
